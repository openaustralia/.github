# .github

This repository holds the [default community health files](https://docs.github.com/en/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file)
for the [OpenAustralia Foundation](https://oaf.org.au) GitHub organisation, and
the org's [profile page](https://docs.github.com/en/account-and-profile/setting-up-and-managing-your-github-profile/customizing-your-profile/personalizing-your-profile#adding-a-public-profile-readme-for-your-organization).

GitHub applies files under `.github/` here to every repository in the
[openaustralia](https://github.com/openaustralia) organisation that doesn't
provide its own. That's why a contributing guide, PR checklist, or issue
template can be missing from a project's own repository and still apply to it.

## What's here

| Path | Purpose |
| --- | --- |
| [`.github/CONTRIBUTING.md`](.github/CONTRIBUTING.md) | Default contributing guide: branching, pull requests, commit sign-off, AI-assisted contributions |
| [`.github/CODEOWNERS`](.github/CODEOWNERS) | Default reviewers for repositories without their own `CODEOWNERS` |
| [`.github/FUNDING.yml`](.github/FUNDING.yml) | Powers the "Sponsor" button across the org's repositories |
| [`.github/ISSUE_TEMPLATE/`](.github/ISSUE_TEMPLATE) | Default bug report and feature request templates |
| [`.github/PULL_REQUEST_TEMPLATE.md`](.github/PULL_REQUEST_TEMPLATE.md) | Default pull request template |
| [`CLA/CLA.md`](CLA/CLA.md) | Contributor Licence Agreement referenced from `CONTRIBUTING.md` |
| [`profile/README.md`](profile/README.md) | The org profile page shown at [github.com/openaustralia](https://github.com/openaustralia) — not this file |

A repository can override any of these by adding its own copy of the same
file. Right to Know's Alaveteli-derived workflow is one example that does.

## Contributing

This repository follows the same [contributing guide](.github/CONTRIBUTING.md)
it defines for everyone else.
